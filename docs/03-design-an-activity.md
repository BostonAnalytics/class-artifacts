# 3. Design one activity

Use the worksheet in [templates/activity-template.md](../templates/activity-template.md). It asks six questions.

1. **Which existing learning objective does it practice?** Copy it from your syllabus. Do not write a new one.
2. **What is the artifact?** Name the one thing students will hand in. If you cannot picture it attached to a discussion post, simplify it.
3. **Where in the lecture does it go?** Right after the lecture segment where that objective is taught. Students try it while the idea is fresh.
4. **What makes each student's input unique?** Their own question or experience, a versioned sheet (version A to F by the last digit of the student ID), or a unique set issued by a web app. Unique inputs make artifacts personal and worth comparing.
5. **How does a student do it from the recording?** The activity slide carries the full instructions, and the same input works later.
6. **How does it feed the discussion?** Which part of your existing prompt does the artifact answer?

## Good activities are small

- One artifact, 15 to 30 minutes.
- Instructions fit on one slide.
- The artifact can be judged against the objective in under a minute.

## A worked example

In MET AD 599, Module 1 Lecture 2, students open the class web app at `/w02/`. They see the analytics questions the class asked in the Week 1 survey, with one worked example done together. Each student picks a question, names its inputs and outputs with a data type and an example value, then decides "Excel or Python?" and ticks where Excel breaks.

That card is the artifact. It answers the Discussion 2 prompt directly: the scenario, how the logic works, and why Python is suitable. See [examples/ad599/w02-walkthrough.md](../examples/ad599/w02-walkthrough.md).
