# Worked example: MET AD 599

**Course:** MET AD 599, Python and SQL for Business Analytics (Boston University Metropolitan College)
**Format:** 14 weeks, six modules of two weeks, weeks 13 and 14 for the term project. Also taught as a 6-week summer term.
**Web app:** [met-ad-599.github.io](https://met-ad-599.github.io/)

## Six modules, six artifacts

| Module | Activity | Artifact |
|---|---|---|
| 1. Python and data structures | Data Passport | Data Passport |
| 2. Logic, strings, functions | Rules Engine | Function plus trace table |
| 3. Algorithms and data science packages | Sort It Out | Step count table plus a recommendation |
| 4. Machine learning and loss functions | Human Regression | ML Evaluation Scorecard |
| 5. SQL basics, joins, grouping | Paper Database | Query log |
| 6. Advanced SQL and Python integration | Leaderboard to Pipeline | Pipeline sketch: ERD and system design |

Each artifact is attached to that module's existing discussion post.
