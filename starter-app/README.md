# Starter web app

```bash
pip install -r requirements.txt
python app.py load-roster roster_sample.csv
python app.py                      # http://localhost:5000
```

Sign in as `thomas` / `apple` (student) or `instructor` / `change-me` (instructor).

- Activities: edit `course.py`
- Roster: `username,password,name,is_admin` CSV
- Tests: `python -m unittest discover tests`

Full guide: [../docs/06-starter-web-app.md](../docs/06-starter-web-app.md)
